# Serpentix

**Snake néon avec musique synthwave dynamique.**

Jouez sur : https://games.hylst.fr/serpentix/

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
# → dist/
```

## Stack

- React 19 + TypeScript 5.9
- Tailwind CSS 4
- Vite 7 + vite-plugin-singlefile
- Web Audio API (synthèse temps réel)
- Canvas 2D
